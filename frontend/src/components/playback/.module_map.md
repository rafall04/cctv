# frontend/src/components/playback/.module_map.md

## Components

- `PlaybackHeader.jsx`: playback route header — title, share trigger, and the camera picker. Wiring only.
- `PlaybackCameraPicker.jsx`: the camera picker itself — thumbnail trigger + dialog with area chips, search, and grouped rows. Replaced a native `<select>`, which rendered as an unreadable wrapped list on Android; matching rules live in `../../utils/playbackCameraPicker.js`. **Shared, despite the name and folder:** `pages/TelegramArchiveLibrary.jsx` (admin) uses it too, having had the identical `<select>` problem. Two optional props keep both callers honest — `metaFor` swaps the per-row sub-line (archive shows segment counts instead of locations) and `allOption` adds an "everything" row that picks `null` (playback watches exactly one camera and omits it). Both default to the playback behaviour, so that page is unaffected.
- `PlaybackOptions.jsx`: access notice + auto-play toggle. Renders BELOW the video so the selector stays directly above the player.
- `PlaybackVideo.jsx`: video element shell, media controls, buffering/seeking/error/empty states.
- `PlaybackTimeline.jsx`: visual segment timeline and timeline click handling surface.
- `PlaybackSegmentList.jsx`: selectable recording segment list.
- `PlaybackUsageGuide.jsx`: static usage guidance with public preview policy copy.
- `PlaybackAccessPanel.jsx`: trial claim + paid package purchase, and the issued access key (with copy-to-clipboard).
- `PlaybackTokenAccess.jsx`: entering/activating an existing access key.

## Boundaries

- Keep media lifecycle, URL state, segment loading, and playback viewer tracking in `../../pages/Playback.jsx`, `../../hooks/playback/*`, and `../../utils/playbackUrlState.js`.
- Keep these components presentational; callbacks and policy values should be passed as props.
- Public playback must not expose admin-only wording or scope. Admin playback should hide public preview limitations.
- Public playback uses the shared `../landing/LandingMobileDock.jsx` for mobile Home/Map/Grid/Favorit/Playback navigation; do not add a second playback-only quick action card.
