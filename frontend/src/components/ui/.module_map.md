# components/ui/.module_map.md

## Read this before writing a new admin class string

The 2026-07 admin audit found the surface had **no primitives** — no Button, Card, Modal, Table or
Field — so every page reinvented them. The measured result: 20+ near-identical card shells, 11
separate dialog implementations (2 with `role="dialog"`, **0** with an Escape handler), 10 stat
tiles, 5 input chromes, 254 `<button>` against 18 `aria-label`, and `focus:outline-none` 125× against
`focus-visible` 25×.

So: **compose from these before writing new classes.** The token, focus and touch-target rules live
inside them precisely so they stop being per-author decisions.

## Design primitives (2026-07)

| Module | Exports | The rule it carries |
|---|---|---|
| `Button.jsx` | `Button`, `IconButton`, `BUTTON_VARIANTS` | `focus-visible:outline` + offset (not `ring` — an outline is not clipped by a scrolling table/drawer and reads correctly on sunken, raised and filled-brand backgrounds). 44px touch target, compacting to 36px only from `sm:` up. `IconButton` **requires** `label`. |
| `Card.jsx` | `Card`, `CardHeader`, `CardTitle`, `CardBody`, `CardFooter` | One panel shell: `rounded-card` + `border-edge` + `bg-surface`. |
| `Badge.jsx` | `Badge`, `StatusDot`, `TONE_CLASSES` | Status colour comes from a token, never a palette pick. `fault` is reserved for actually broken; maintenance is `warn`. `StatusDot` requires a `label` (a dot is never the sole carrier of meaning). |
| `PageHeader.jsx` | `PageHeader` | Every route gets exactly one `h1`. |
| `Modal.jsx` | `Modal`, `ModalFooter` | `role="dialog"` + `aria-modal` + `aria-labelledby`, focus trap, Escape, body-scroll lock, `z-modal` (above `z-shell`). |
| `DataTable.jsx` | `TableShell`, `Table`, `THead`, `TBody`, `TR`, `TH`, `TD`, `SortableTH` | Horizontal scroll is contained by the shell, never by a page ancestor. `SortableTH` sets `aria-sort`. `TD mono` for numeric columns. |
| `Tabs.jsx` | `Tabs`, `TabPanel` | `role="tablist"`/`tab`/`tabpanel`, `aria-selected`, roving tabindex, arrow/Home/End traversal. Active tab follows the runtime brand colour. |
| `StatTile.jsx` | `StatTile`, `MeterBar`, `SegmentedBar`, `loadTone` | Values render mono/tabular (dashboards poll; a proportional face re-lays-out the row when a digit's width changes). `loadTone()` derives meter colour from the VALUE — shared by CPU/memory so "amber" means one thing. `icon` is decorative (aria-hidden); use `meta` for content that must stay announced. |
| `Toolbar.jsx` | `Toolbar`, `SearchInput` | List-page filter strip; `min-w-0` on the growing child so Android font scaling cannot push the row past the viewport. |
| `Field.jsx` | `Field`, `inputClasses` | Generates and wires its own `id`/`htmlFor`, `aria-describedby`, `aria-invalid`, `role="alert"` on the error. Visible label always — never placeholder-only. |

`primitives.test.jsx` locks the accessibility contracts above. If you change a primitive and that
file goes red, the contract is what broke — not the test.

## App-level widgets (predate the primitives)

- `Alert.jsx`, `Toast.jsx`, `ToastContainer.jsx` — notification surfaces; `ToastContainer` is the
  global one mounted in `App.jsx` (the one in `contexts/ToastContext.jsx` is landing-only).
- `ConfirmDialog.jsx` — destructive-action confirm, driven by `contexts/ConfirmContext.jsx`.
- `FormField.jsx` — heavier field with validation state + character count; `Field.jsx` is the
  lighter one for plain admin config forms.
- `EmptyState.jsx`, `Skeleton.jsx` — empty/loading states.
- `NetworkStatusBanner.jsx` — offline banner used by both shells.
- `Icons.jsx`, `ThemeSwitcher.jsx`.

## Rules

- Token and scale definitions: `src/index.css` + `tailwind.config.js`. Usage rules and the status
  semantics: `docs/frontend-guide.md`.
- **Never write a bare `z-[…]`** — use the named layering scale.
- Tailwind silently drops a class whose token does not exist (`text-status-ok` once shipped as *no
  colour at all*). The `guardrails.test.js` typo-proofing test mirrors the valid token list; extend
  both together when a token is genuinely added.
