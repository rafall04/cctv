# backend/utils/.module_map.md

## Utilities

- `authCookieOptions.js`: request-aware HttpOnly auth cookie option helper for login and refresh responses, including direct-IP and HTTPS proxy behavior.
- `cameraDelivery.js`: camera delivery/source profile normalization helpers.
- `cameraProjection.js`: camera read model/projection helpers.
- `internalIngestPolicy.js`: internal ingest policy helper functions.
- `thumbnailStrategyPolicy.js`: camera thumbnail capture strategy normalizer used by camera writes and thumbnail generation.
- `outboundUrlPolicy.js`: whether an operator-supplied OUTBOUND link (an affiliate partner's shop or product page) may be stored and redirected to. Parses with `new URL()` rather than regex-matching, because the consumer is a browser following `Location:` and only the same algorithm agrees with it: https only, real hostname, no `user:pass@`, plus a raw-string scan for control characters (`new URL()` silently strips tab/CR/LF, so a regex and the parser can otherwise disagree about the destination). Deliberately carries NO private-IP blocklist — unlike `rtspUrlPolicy`, nothing server-side ever dials these URLs.
- `affiliateCountThrottle.js`: capped, swept in-memory window that stops one visitor's repeated impression/click from inflating the daily affiliate rollup. Bounded on purpose — an uncapped Map keyed by client IP is a memory leak with a flood attached.

## Verification

- Auth cookie helper: `npm test -- authCookieOptions.test.js`.
- Camera utility helpers: run their matching backend test files plus impacted service tests.
- `ffmpegCapabilities.js`: cached `ffmpeg -version` probe for version-specific option names (RTSP socket timeout is `-stimeout` on 4.x, `-timeout` on 5+).
